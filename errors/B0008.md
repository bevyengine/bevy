# B0008

A runtime warning.

This error occurs when an exclusive system parameter, such as `&mut World`, is
combined with another parameter that accesses the world. `&mut World` already
has mutable access to every entity and resource, so it cannot be used in the
same system with a `Query`, `Res`, `ResMut`, or another world-accessing
parameter.

Erroneous code example:

```rust,should_panic
use bevy::prelude::*;

fn conflicting_system(_: &mut World, _: Query<Entity>) {}

fn main() {
    App::new()
        .add_plugins(MinimalPlugins)
        .add_systems(Update, conflicting_system)
        .run();
}
```

## Possible solutions

If the exclusive access is only needed to create entities or make deferred
changes, use [`Commands`](https://docs.rs/bevy/latest/bevy/ecs/system/struct.Commands.html):

```rust,no_run
use bevy::prelude::*;

fn spawn_system(mut commands: Commands) {
    commands.spawn_empty();
}
```

If the system needs a query or resource as well as direct world access, move
the non-exclusive parameter into a cached [`SystemState`](https://docs.rs/bevy/latest/bevy/ecs/system/struct.SystemState.html)
and access it from an exclusive system:

```rust,no_run
use bevy::prelude::*;
use bevy::ecs::system::SystemState;

#[derive(Resource)]
struct Score(u32);

fn exclusive_system(world: &mut World) {
    let mut state: SystemState<(Query<Entity>, ResMut<Score>)> =
        SystemState::new(world);
    let (entities, mut score) = state.get_mut(world).unwrap();
    score.0 += entities.iter().count() as u32;
}
```

For a single query, a [`QueryState`](https://docs.rs/bevy/latest/bevy/ecs/query/struct.QueryState.html)
can be stored and updated manually from the exclusive system. Both approaches
keep the query state separate from the system's exclusive world borrow.
