# B0007

A runtime warning.

This error occurs when two different kinds of system parameters request
conflicting access to the same data. A common example is querying every entity
with [`EntityMut`](https://docs.rs/bevy/latest/bevy/ecs/query/struct.EntityMut.html)
while also requesting a resource. Resources are stored on entities internally,
so an unrestricted mutable entity query also accesses the resource.

Erroneous code example:

```rust,should_panic
use bevy::prelude::*;

#[derive(Resource)]
struct Score(u32);

fn conflicting_system(_: Query<EntityMut>, _: ResMut<Score>) {}

fn main() {
    App::new()
        .add_plugins(MinimalPlugins)
        .insert_resource(Score(0))
        .add_systems(Update, conflicting_system)
        .run();
}
```

## Possible solutions

If the query does not need to inspect resource entities, exclude them with
`Without<IsResource>`:

```rust,no_run
use bevy::prelude::*;
use bevy::ecs::resource::IsResource;

#[derive(Resource)]
struct Score(u32);

fn compatible_system(
    _: Query<EntityMut, Without<IsResource>>,
    _: ResMut<Score>,
) {}
```

If both parameters are needed and can be used at separate times, put them in a
[`ParamSet`](https://docs.rs/bevy/latest/bevy/ecs/system/struct.ParamSet.html).
The `ParamSet` prevents the conflicting borrows from being active at the same
time:

```rust,no_run
use bevy::prelude::*;

#[derive(Resource)]
struct Score(u32);

fn compatible_system(mut params: ParamSet<(Query<EntityMut>, ResMut<Score>)>) {
    let _entities = params.p0().iter_mut().count();
    params.p1().0 += 1;
}
```

The same pattern applies to other parameters that represent the same storage,
such as `MessageWriter<M>` and `ResMut<Messages<M>>`.
