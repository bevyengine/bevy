# B0009

A runtime warning.

This error occurs when a system uses both [`MessageReader`](https://docs.rs/bevy/latest/bevy/ecs/message/struct.MessageReader.html)
and [`MessageWriter`](https://docs.rs/bevy/latest/bevy/ecs/message/struct.MessageWriter.html)
for the same message type. Reading and writing the same message queue requires
conflicting access.

Erroneous code example:

```rust,should_panic
use bevy::prelude::*;

#[derive(Message)]
struct MyMessage;

fn conflicting_system(_: MessageReader<MyMessage>, _: MessageWriter<MyMessage>) {}

fn main() {
    App::new()
        .add_plugins(MinimalPlugins)
        .add_message::<MyMessage>()
        .add_systems(Update, conflicting_system)
        .run();
}
```

## Possible solutions

Use [`MessageMutator`](https://docs.rs/bevy/latest/bevy/ecs/message/struct.MessageMutator.html)
when one system needs to read and write the same message type. It combines the
two operations into one parameter:

```rust,no_run
use bevy::prelude::*;

#[derive(Message)]
struct MyMessage;

fn compatible_system(mut messages: MessageMutator<MyMessage>) {
    for _message in messages.read() {
        // Read existing messages.
    }
    messages.write(MyMessage);
}
```

If the reader and writer must remain separate, use a
[`ParamSet`](https://docs.rs/bevy/latest/bevy/ecs/system/struct.ParamSet.html)
and access them at separate times. Prefer `MessageMutator` when that simpler
single-parameter API is sufficient.
